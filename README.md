# 🧠 Face Recognition using Siamese Network (One-Shot Learning)

A face recognition system built using a **Siamese Neural Network** trained on the **Labeled Faces in the Wild (LFW)** dataset. This project leverages **One-Shot Learning** to authenticate a person using only a few reference images.

## 📌 Problem Statement

Traditional face recognition systems require large amounts of labeled data per person. This project solves the problem using **One-Shot Learning**, where the model can verify identities with minimal examples.



## 🧪 Model Details

- **Architecture**: Twin CNN branches with shared weights.
- **Loss Function**: Contrastive Loss / Binary Crossentropy.
- **Framework**: TensorFlow / Keras
- **Dataset**: [LFW (Labeled Faces in the Wild)](http://vis-www.cs.umass.edu/lfw/)
